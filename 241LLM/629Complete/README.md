AC_Net（Actor-Critic网络）：
类 AC_Net（Actor-Critic网络）：

初始化方法：
   1. 构建策略网络（Actor）
      对于每一层（共num_layers层）：
         - 添加全连接层（layer_size个神经元）
         - 添加批归一化层
         - 添加ELU激活函数
         - 添加Dropout层（训练时）
      - 添加输出层（n_actions个动作）
   
   2. 构建价值网络（Critic）
      对于每一层（共num_layers层）：
         - 添加全连接层（layer_size个神经元）
         - 添加批归一化层
         - 添加ELU激活函数
         - 添加Dropout层（训练时）
      - 添加输出层（1个价值输出）
   
   3. 构建旧策略网络（用于PPO）
   4. 初始化探索参数（温度、噪声缩放）
   5. 初始化PPO参数（裁剪比率、epochs、缓冲区）

前向传播方法（策略网络）：
   输入：状态特征
   1. 通过隐藏层传播
   2. 应用批归一化和激活函数
   3. 如果训练中：添加噪声和dropout
   4. 计算动作logits
   5. 应用稳定的softmax获得动作概率
   输出：动作概率分布

稳定softmax方法：
   1. 动态调整logits裁剪范围
   2. 使用tanh进行软裁剪
   3. 温度缩放
   4. 双精度计算防止数值溢出
   5. 确保概率和为1
   
PPO损失计算方法：
   输入：状态、动作、优势、旧策略
   1. 计算当前策略概率
   2. 计算旧策略概率
   3. 计算概率比率（使用log空间）
   4. PPO裁剪：clip(ratio, 1-ε, 1+ε)
   5. 标准化优势值
   6. 计算代理损失：min(ratio*A, clipped_ratio*A)
   7. 添加熵正则化
   输出：总损失、策略损失、熵

梯度计算和裁剪方法：
   1. 计算策略损失和价值损失
   2. 反向传播获取梯度
   3. 层级别梯度裁剪（异常大的梯度）
   4. 全局梯度裁剪（自适应范数）
   5. 监控梯度健康状态
   6. 动态调整裁剪范数

PPO更新方法：
   1. 更新旧策略网络权重
   2. 对于每个epoch（共ppo_epochs次）：
      2.1 打乱数据
      2.2 对于每个小批量：
          - 计算损失和梯度
          - 应用梯度更新
          - 监控梯度异常
   3. 衰减探索参数
   4. 清空PPO缓冲区


Agent627.py
类 DeepRMSA_Agent（深度RMSA智能体）：

初始化方法：
   1. 设置网络参数（链路数、节点数、频谱槽数）
   2. 创建本地AC网络
   3. 初始化频谱图管理器（线程安全）
   4. 初始化请求管理器（防止内存泄漏）
   5. 创建特征归一化器（自适应）
   6. 创建经验缓冲区
   7. 预处理候选路径（缓存优化）

RMSA主循环方法：
   当未停止训练时：
      1. 更新本地网络（从全局网络复制权重）
      
      2. 对于每个episode：
         初始化episode统计
         
         当步数 < episode_size时：
            2.1 释放过期请求
                - 更新TTL（生存时间）
                - 释放过期频谱槽
            
            2.2 生成新的连接请求
                - 随机选择源-目的节点对
                - 随机生成带宽需求（25-100）
                - 生成服务时间（指数分布）
            
            2.3 构建输入特征
                - 源节点one-hot编码
                - 目的节点one-hot编码
                - 对于每条候选路径：
                  * 计算所需频谱槽数
                  * 获取可用频谱状态
                  * 提取频谱特征（位置、连续性、可用总数等）
                  * 归一化特征值
            
            2.4 神经网络决策
                - 输入特征到本地网络
                - 获取动作概率分布和价值估计
                - ε-贪婪选择动作
                  如果 random() < ε：随机选择
                  否则：选择最大概率动作
            
            2.5 执行动作
                - 解码动作（路径ID + 频谱位置ID）
                - 检查路径可用性
                - 检查频谱可用性
                - 如果可行：
                  * 分配频谱资源
                  * 更新频谱图
                  * 记录请求信息
                  * 奖励 = 1
                - 否则：
                  * 阻塞请求
                  * 奖励 = -1
            
            2.6 存储经验
                - 保存(状态, 动作, 奖励, 价值)到缓冲区
            
            2.7 批量训练
                如果缓冲区大小 >= batch_size：
                   - 采样批量数据
                   - 计算折扣奖励
                   - 计算优势函数
                   - 更新网络参数
         
         3. Episode结束处理
            - 计算阻塞率
            - 记录统计信息
            - 更新监控器
            - 检查早停条件
            
         4. 定期任务（Agent 0负责）
            - 打印训练进度
            - 保存模型检查点
            - 写入TensorBoard日志
            - 保存JSON日志

频谱管理方法：
   标记连续频谱块：
      1. 扫描频谱向量
      2. 识别连续可用块
      3. 返回块的起始位置和长度
   
   判断频谱可用性：
      1. 找到所有足够大的频谱块
      2. 选择最佳适配块（最小化碎片）
      3. 返回分配的起始和结束位置
   
   释放过期频谱：
      1. 锁定相关链路
      2. 更新TTL值
      3. 释放TTL<=0的频谱槽
      4. 解锁链路

特征归一化方法：
   自适应归一化器：
      1. 预热阶段：使用分位数归一化
      2. 正常阶段：使用运行均值和标准差
      3. 动态更新统计信息
      4. 裁剪到[-3, 3]范围
